Computer Programming Basics

Have you ever wondered how the apps, websites, and games you use actually work? Programming is what makes much of today's technology possible, from browsing the internet and using mobile apps to playing video games and shopping online. It involves writing instructions that tell computers how to process information, perform tasks, and produce specific results. Learning the basics of programming provides a foundation for understanding how software is created and how the technology we rely on every day works.

What is programming?

Programming is the process of writing instructions using a programming language to tell a computer how to perform specific tasks. These instructions when written in a programming language, are called code. In other words, programming is telling the computer what to do. To better understand programming, think of following a recipe. A recipe contains a series of instructions that must be followed in a particular order to prepare a meal successfully. Each step provides information about what needs to be done. A computer works in a similar way. It follows a set of instructions, written as code, step by step, to complete a task. However, computers require instructions to be clear, precise, and specific. Unlike humans, computers cannot easily interpret missing information or guess what we mean. If the code contains incomplete, unclear, or incorrect instructions, the computer may produce an unexpected result or fail to complete the task. This is why programmers must carefully write and organize their code to ensure the computer recceives the correct instructions.

What is a programming language?

A programming language is a formal language used by developers to write instructions that tell computers how to perform specific tasks. It acts as a bridge between humans and computers, allowing developers to write instructions in a human-readable format that can be translated or interpreted into machine code. Machine code consists of binary instructions made up of 0s and 1s because computers use the binary number system to represent and process information. These instructions can then be executed by the computer's processor. Each programming language has its own set of rules, known as syntax, and features that help developers create software, applications, websites, and other programs.

Here are examples of some popular programming languages:

  • Python: A beginner-friendly, versatile language commonly used for artificial intelligence, automation, machine learning, data science, and web development.
  • Javascript: A programming language primarily used to create interactive websites, web applications, and server-side applications.
  • Java: An object-oriented language widely used for enterprise software development, backend systems, and Android application development.
  • C++: A high-performance programming language used for game development, operating systems, and resource-intensive applications.
  • C#: A modern, object-oriented language developed by Microsoft, commonly used for Windows applications, web development, and game development with Unity.
  • SQL (Structured Query Language): A language used to create, manage, query, and manipulate data stored in relational databases.

What is an IDE?

An IDE (Integrated Development Environment) is a software application that provides tools for programmers to write, edit, run, and debug code in one place.

Examples of popular IDEs: VS Code, Visual Studio, IntelliJ IDEA, and Pycharm

The Process of Programming

Programming begins with identifying a problem or task that needs to be solved. Before writing code, programmers develop a plan by breaking the problem into smaller steps. These steps form an algorithm, which is a set of logical instructions that describes how to solve a problem.

Next, programmers use a programming language, such as Python, Java, or C++, to translate those instructions into source code. This code is written using an IDE (Integrated Development Environment), which provides tools to write, organize, run, and debug programs.

Once the code is written, it must be processed by a compiler or interpreter, depending on the programming language. These tools translate or execute the code so the computer can carry out the instructions. The result is called the output, which is what the program produces, such as displaying text, performing calculations, or processing information.

After execution, programmers perform testing to make sure the program works correctly. If something doesn't work as expected, they use debugging to find and fix errors, commonly called bugs.

This process of planning, coding, executing, testing, and debugging is repeated throughout development. Programmers continually make improvements to ensure their programs function correctly, efficiently, and reliably.

Core Programming Concepts

Programming languages share several fundamental concepts that help developers write instructions, solve problems, and build applications. Understanding these basics is essential when learning any programming language.

  • Variables: Named locations used to store data that a program can use or change.
    Example: name = "John" stores the text "John" in a variable called name.
  • Data Types: Identify the type of information being stored.
      Examples:
    • String: "Hello" (text)
    • Integer: 25 (whole number)
    • Float: 3.14 (decimal number)
    • Boolean: True or False (yes/no values)
  • Operators: Symbols used to perform calculations, compare values, and evaluate conditions.
    Example: 5 + 3, + is the operator and 2 and 3 are operands.
  • Conditional Statements: Allow a program to make decisions based on certain conditions.
    Example: 
     age = int(input("Enter your age: "))
 
 if age >= 18:
     print("Adult")
 else:
     print("Minor")
    In this example, the program checks whether a person is of legal age (18 or older) using the condition age >= 18. If the condition is true, the if branch executes and prints Adult. Otherwise, the else branch executes and prints Minor.
  • Loops: Repeat a block of code multiple times.
    Example: 
     for i in range(3):
    print("Welcome to the IT Corner!")
    Output: 
     Welcome to the IT Corner!
 Welcome to the IT Corner!
 Welcome to the IT Corner!
    In this example, the program uses a for loop to display the message Welcome to the IT Corner! three times. The range(3) tells the program to repeat the instruction three times.
  • Functions: Reusable blocks of code designed to perform specific tasks.
    Example: 
     def add_numbers(a, b):
    sum = a + b
    print("The sum is:", sum)
 add_numbers(5, 3)
 add_numbers(10, 3)
    Output: 
     The sum is: 8
 The sum is: 13
    In this example, the program defines a function called add_numbers() to add two numbers. The function is called twice with different values, demonstrating how the same function can be reused to perform a task.
  • Arrays and Lists: Used to store multiple values in a single collection.
    Example: 
     groceries = ["Milk", "Bread", "Eggs", "Apples"]
 print(groceries)
    Output:
    ['Milk', 'Bread', 'Eggs', 'Apples']
    In this example, the groceries list holds multiple grocery items, such as Milk, Bread, Eggs, and Apples, under one variable name. Instead of creating a separate variable for each item, a list groups related values together. Each grocery item is stored as an element in the list.
  • Comments: Notes added to code to explain what it does. They are ignored when the program runs.
    Example: 
     # Display a welcome message
 print("Welcome to the IT Corner!")
    Output:
    Welcome to the IT Corner!
    In this example, the line starting with # is a comment. Comments are used to add notes or explanations to code. They are ignored during program execution.

    • NOTE: These examples use Python, a high-level programming language known for its clear and readable syntax, making it suitable for introducing beginners to fundamental programming concepts.

Applying Programming Fundamentals

Programming is about using instructions, logic, and problem-solving to tell computers what to do. By understanding what programming is, becoming familiar with programming languages and development tools, and learning fundamental programming concepts, you have the foundation needed to start writing code and building applications.

Learning to program takes practice and patience. Start with the basics, experiment with simple programs, and gradually work toward more complex projects. The more you practice, the more comfortable you'll become with understanding and writing code.
